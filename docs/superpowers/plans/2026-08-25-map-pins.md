# MAP PINS(v2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 管理者専用ページ`/admin/map-pins`から、名前・説明・カテゴリ(固定6種)・アイコン(用意した12種から選択)・位置(地図クリックで指定)を持つピンを登録・編集・削除できるようにし、`/map`ページで全ユーザーに表示する。

**Architecture:** 新規テーブル`map_pins`をSQLiteに追加し、`server/utils/mapPins.ts`でCRUD+バリデーションを行う。既存の`components/AsakusaMap.vue`(Leaflet+MapLibre)に`pins`表示propと`pickMode`座標ピックpropを追加して、公開`/map`ページと管理画面の両方で同じ地図コンポーネントを再利用する。カテゴリ名は6言語(ja/en/ko/zh-Hant/zh-Hans/pt)ラベルを持つが、管理画面自体は既存admin配下ページと同様に英語固定UIとする。

**Tech Stack:** Nuxt 3 / Vue 3, better-sqlite3, Leaflet 1.9 + MapLibre GL(既存`AsakusaMap.vue`のスタック), Nuxt UI v3(`UForm`/`UFormField`/`UModal`等), zod, `@iconify/vue`(`loadIcon`), Vitest + happy-dom

参照design: `docs/superpowers/specs/2026-08-25-map-pins-design.md`

## Global Constraints

- git操作(`add`/`commit`含む)は人間が行う。各タスクの"Commit"ステップはコマンドを提示するのみで、実行者(このプランを進める人間またはエージェント)は実際にコマンドを叩かず、人間に実行を依頼すること(このプロジェクトの`CLAUDE.md`の絶対ルール)
- ピンのカテゴリは固定6種のみ: `spot` / `restaurant` / `shopping` / `toilet` / `event` / `other`(英語ラベルはそれぞれ `Sightseeing Spot` / `Restaurant` / `Shopping` / `Restroom` / `Event Venue` / `Other`)。動的追加はスコープ外
- ピンのアイコンは固定12種のみ、iconifyのコロン区切り形式(`lucide:map-pin`など)で保持する。`i-lucide-xxx`形式は`loadIcon()`のパースを壊すので使わないこと
- ピンの名前・説明は単一言語の自由入力(多言語翻訳の仕組みは追加しない)。カテゴリ名のみ`utils/i18n/categoryLabels.ts`と同じ構造で6言語ラベルを持つ
- 管理画面(`pages/admin/map-pins.vue`)は`pages/admin/articles.vue`・`pages/admin/sources.vue`と同様、UI文言は英語固定で`useUiText()`は使わない
- `/api/admin/map-pins/*`の全エンドポイントは`requireAdminUser(db, event)`で管理者ガードする(`server/utils/admin.ts`の既存関数、変更不要)
- `/api/map-pins`(公開一覧)は認証不要。`/map`ページは既存方針通り未ログインでも閲覧可能なまま変更しない
- 今回のスコープでは`/map`側のカテゴリ絞り込みフィルタは作らない(non-goal)
- 既存の`tests/e2e/map.test.ts`を壊さないこと

```ts
import type Database from 'better-sqlite3'
import { createError } from 'h3'
import { PIN_CATEGORIES, PIN_ICONS, type MapPin } from '../../utils/mapPins'

export function listMapPins(db: Database.Database): MapPin[] {
  return db
    .prepare(`SELECT id, name, description, category, icon, lat, lng, created_at FROM map_pins ORDER BY id DESC`)
    .all() as MapPin[]
}

export interface MapPinInput {
  name: string
  description: string
  category: string
  icon: string
  lat: number
  lng: number
}

function validateInput(input: MapPinInput): void {
  if (!input.name || !input.name.trim()) {
    throw createError({ statusCode: 400, message: 'name is required' })
  }
  if (!(PIN_CATEGORIES as readonly string[]).includes(input.category)) {
    throw createError({ statusCode: 400, message: 'invalid category' })
  }
  if (!(PIN_ICONS as readonly string[]).includes(input.icon)) {
    throw createError({ statusCode: 400, message: 'invalid icon' })
  }
  if (typeof input.lat !== 'number' || Number.isNaN(input.lat) || input.lat < -90 || input.lat > 90) {
    throw createError({ statusCode: 400, message: 'invalid lat' })
  }
  if (typeof input.lng !== 'number' || Number.isNaN(input.lng) || input.lng < -180 || input.lng > 180) {
    throw createError({ statusCode: 400, message: 'invalid lng' })
  }
}

export function createMapPin(db: Database.Database, input: MapPinInput): MapPin {
  validateInput(input)
  const name = input.name.trim()
  const createdAt = new Date().toISOString()
  const result = db
    .prepare(
      `INSERT INTO map_pins (name, description, category, icon, lat, lng, created_at) VALUES (?, ?, ?, ?, ?, ?, ?)`
    )
    .run(name, input.description, input.category, input.icon, input.lat, input.lng, createdAt)
  return {
    id: Number(result.lastInsertRowid),
    name,
    description: input.description,
    category: input.category as MapPin['category'],
    icon: input.icon as MapPin['icon'],
    lat: input.lat,
    lng: input.lng,
    created_at: createdAt
  }
}

export function updateMapPin(db: Database.Database, id: number, input: MapPinInput): MapPin {
  validateInput(input)
  const existing = db.prepare(`SELECT id FROM map_pins WHERE id = ?`).get(id)
  if (!existing) {
    throw createError({ statusCode: 404, message: 'pin not found' })
  }
  const name = input.name.trim()
  db.prepare(`UPDATE map_pins SET name = ?, description = ?, category = ?, icon = ?, lat = ?, lng = ? WHERE id = ?`)
    .run(name, input.description, input.category, input.icon, input.lat, input.lng, id)
  return db
    .prepare(`SELECT id, name, description, category, icon, lat, lng, created_at FROM map_pins WHERE id = ?`)
    .get(id) as MapPin
}

export function deleteMapPin(db: Database.Database, id: number): void {
  const existing = db.prepare(`SELECT id FROM map_pins WHERE id = ?`).get(id)
  if (!existing) {
    throw createError({ statusCode: 404, message: 'pin not found' })
  }
  db.prepare(`DELETE FROM map_pins WHERE id = ?`).run(id)
}
```
