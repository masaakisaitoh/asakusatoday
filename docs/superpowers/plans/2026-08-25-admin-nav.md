# 管理画面: ナビゲーションメニュー Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/admin/drafts`・`/admin/articles`・`/admin/sources`の3画面に共通のナビゲーションコンポーネント`AdminNav`を追加し、管理画面同士を行き来できるようにする。

**Architecture:** 新規の`components/AdminNav.vue`が管理画面一覧(`links`配列)を唯一の情報源として持ち、`NuxtLink`の`active-class`で現在ページをハイライトする。Nuxtのcomponents自動importにより、3つの`pages/admin/*.vue`はそれぞれ`<h1>`の直前に`<AdminNav />`を1行追加するだけで済む。

**Tech Stack:** Nuxt 3 / Vue 3 (`NuxtLink`, components自動import) / Vitest / `@vue/test-utils`

## Global Constraints

- `AdminNav.vue`内の`links`配列 `[{ to: '/admin/drafts', label: 'Drafts' }, { to: '/admin/articles', label: 'Articles' }, { to: '/admin/sources', label: 'Sources' }]` が管理画面一覧の唯一の情報源
- Nuxt UI(`UButton`等)は使わない。素の`NuxtLink`+tailwindクラスのみ
- 各`pages/admin/*.vue`の`<script setup>`側は変更しない。テンプレートに`<AdminNav />`を1行追加するのみ(Nuxtのcomponents自動importなので`import`文は不要)
- git操作(add/commit等)は人間が行う。各タスクの最後は**実行者が`git`コマンドを直接叩かず、変更内容をまとめて報告し、人間にコミットしてもらう**こと

### Task 1: `AdminNav`コンポーネントを追加する

**Files:**
- Create: `components/AdminNav.vue`
- Test: `components/AdminNav.test.ts`

**Interfaces:**
- Consumes: なし(新規コンポーネント、propsも取らない)
- Produces: `<AdminNav />`コンポーネント(Nuxt components自動importでグローバル登録される) — 後続タスク(Task 2)が`pages/admin/drafts.vue`・`pages/admin/articles.vue`・`pages/admin/sources.vue`のテンプレートから`<AdminNav />`として呼び出す

- [ ] **Step 1: 失敗するテストを書く**

`components/AdminNav.test.ts`を新規作成:

```ts
import { describe, it, expect } from 'vitest'
import { mount } from '@vue/test-utils'
import AdminNav from './AdminNav.vue'

const stubs = {
  NuxtLink: { props: ['to'], template: '<a :href="to"><slot /></a>' }
}

describe('AdminNav', () => {
  it('renders links to all three admin pages', () => {
    const wrapper = mount(AdminNav, { global: { stubs } })
    const hrefs = wrapper.findAll('a').map((a) => a.attributes('href'))
    expect(hrefs).toEqual(['/admin/drafts', '/admin/articles', '/admin/sources'])
  })

  it('renders the expected labels', () => {
    const wrapper = mount(AdminNav, { global: { stubs } })
    expect(wrapper.text()).toContain('Drafts')
    expect(wrapper.text()).toContain('Articles')
    expect(wrapper.text()).toContain('Sources')
  })
})
```

- [ ] **Step 2: テストを実行して失敗を確認する**

Run: `npx vitest run components/AdminNav.test.ts`
Expected: FAIL(`./AdminNav.vue`が存在しない、importエラー)

- [ ] **Step 3: `AdminNav.vue`を実装する**

`components/AdminNav.vue`を新規作成:

```vue
<script setup lang="ts">
const links = [
  { to: '/admin/drafts', label: 'Drafts' },
  { to: '/admin/articles', label: 'Articles' },
  { to: '/admin/sources', label: 'Sources' }
]
</script>

<template>
  <nav class="flex gap-4 mb-6 text-sm">
    <NuxtLink
      v-for="link in links"
      :key="link.to"
      :to="link.to"
      class="text-muted hover:text-primary"
      active-class="text-primary font-bold"
    >
      {{ link.label }}
    </NuxtLink>
  </nav>
</template>
```

- [ ] **Step 4: テストを実行して成功を確認する**

Run: `npx vitest run components/AdminNav.test.ts`
Expected: PASS(2 tests)

- [ ] **Step 5: 変更内容を報告する(人間がコミット)**

変更ファイル: `components/AdminNav.vue`(新規), `components/AdminNav.test.ts`(新規)。コミットメッセージ案: `feat: add AdminNav component for admin page navigation`
